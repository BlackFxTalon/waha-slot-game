# game-ui — Delta

## ADDED Requirements

### Requirement: Портретная раскладка

На вертикальных экранах (высота заметно больше ширины) игра MUST использовать портретный дизайн 1080×1920: сетка барабанов 5×3 крупно в верхней трети, панели баланса/ставки под сеткой, кнопки управления (спин/авто/турбо) крупными целями в нижней зоне. Фон MUST масштабироваться по принципу cover с центрированием на композиционном центре собора. При повороте устройства игра MUST пересоздаваться под новый режим с сохранением баланса, ставки и настроек.

#### Scenario: Портретный запуск
- **WHEN** страница открывается на вертикальном экране (например, 390×844)
- **THEN** сетка барабанов занимает большую часть ширины, панели и кнопки управления доступны без скролла, спин выполняется

#### Scenario: Поворот устройства
- **WHEN** игрок поворачивает устройство во время сессии
- **THEN** игра перестраивается под новый режим, баланс и настройки сохраняются

### Requirement: Тултипы кнопок

Каждая кнопка HUD MUST иметь тултип с назначением (и горячей клавишей, если есть), показываемый при наведении указателя. Тултипы кнопок в верхней трети экрана MUST отображаться под кнопкой (иначе обрезаются краем окна), остальных — над кнопкой. Тултип MUST исчезать при уходе указателя и не MUST перехватывать клики.

#### Scenario: Тултип турбо-кнопки
- **WHEN** игрок наводит указатель на кнопку турбо
- **THEN** появляется подпись «ТУРБО — УСКОРЕННЫЕ БАРАБАНЫ», исчезает при уходе

### Requirement: Информативная кнопка турбо

Кнопка турбо MUST быть текстовой («ТУРБО») с индикатором состояния ВКЛ/ВЫКЛ и визуальным выделением активного состояния.

#### Scenario: Состояние видно
- **WHEN** игрок включает турбо
- **THEN** кнопка подсвечивается и индикатор меняется на «ВКЛ»
