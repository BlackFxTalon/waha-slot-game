# slot-math — Delta

## MODIFIED Requirements

### Requirement: Оценка выигрыша по линиям

Система MUST оценивать выигрыш по 10 фиксированным линиям слева направо: серия из 3, 4 или 5 позиций, где каждая позиция содержит либо одинаковый символ, либо wild. Wild MUST заменять любой символ; если серия состоит только из wild, она оплачивается по таблице wild. Для каждой линии система MUST выбирать лучший вариант из всех кандидатов (максимальная выплата). Wild-символов на ленте MUST быть 1–2 позиции на барабан.

#### Scenario: Выигрыш 3+ символов слева
- **WHEN** на линии первые 3 барабана содержат одинаковый символ, а 4-й — другой
- **THEN** линия оплачивается как «3 в ряд» по таблице выплат

#### Scenario: Младшие пары не оплачиваются
- **WHEN** на линии только 2 одинаковых символа с края (без wild)
- **THEN** линия не приносит выигрыша

#### Scenario: Несколько линий суммируются
- **WHEN** одна сетка даёт выигрыш более чем на одной линии
- **THEN** общая выплата равна сумме выплат всех выигравших линий

#### Scenario: Wild замещает недостающий символ
- **WHEN** на линии первые 3 позиции содержат crown, а 4-я — wild
- **THEN** линия оплачивается как 4 короны

#### Scenario: Чисто wild-серия оплачивается по таблице wild
- **WHEN** на линии первые 3 позиции — wild, 4-я — другой символ
- **THEN** линия оплачивается как 3 wild

#### Scenario: Выбирается лучший кандидат
- **WHEN** на линии wild-позиции позволяют собрать серии разных символов
- **THEN** выплачивается вариант с максимальной суммой, одна линия даёт один выигрыш

### Requirement: Таблица выплат

Система MUST содержать таблицу выплат для 10 символов (wild + 9 базовых) с множителями за 3/4/5 совпадений. Выплаты wild MUST быть строго выше выплат короны. Более ценные символы MUST иметь строго большие множители, чем менее ценные на той же длине.

#### Scenario: Иерархия выплат корректна
- **WHEN** таблица выплат загружается
- **THEN** для каждого символа выплата за 5 больше выплаты за 4, которая больше выплаты за 3, и ни один символ не оплачивает пары

#### Scenario: Wild дороже короны
- **WHEN** таблица выплат загружается
- **THEN** выплата wild за любую длину серии строго больше выплаты короны той же длины

## ADDED Requirements

### Requirement: Контроль RTP с wild

Математическая модель с wild MUST иметь расчётный RTP в диапазоне 92–96%, проверенный симуляцией Монте-Карло (`tools/simulate.ts`) с той же конфигурацией лент и таблицей выплат, что и игра.

#### Scenario: Симуляция подтверждает RTP с wild
- **WHEN** запускается `npm run simulate` (10 млн спинов)
- **THEN** RTP находится в диапазоне 92–96%
