# Design: add-grim-fortune-slot

## Context

Проект создаётся с нуля вокруг двух готовых изображений: атлас символов 1254×1254 (сетка 3×3, ячейки 418×418) и фон-рамка 1672×941 с тёмной центральной зоной под барабаны. Стек: pixi.js v8, TypeScript, Vite. Серверной части нет — вся математика локальная, прогресс — в localStorage.

## Goals / Non-Goals

**Goals:**
- Играбельный слот 5×3 / 10 линий с презентацией уровня «коммерческий демо»: поочерёдная остановка, anticipation, трассы линий, Big Win, автоигра, paytable.
- Прозрачная математика: одна конфигурация (strips + paytable) используется и игрой, и симулятором RTP.
- Нарезка ассетов в рантайме по координатам сетки — ноль препроцессинга арта.
- Синтез звука WebAudio — ноль аудиофайлов и сетевых запросов.

**Non-Goals:**
- Нет сервера, аккаунтов, реальных денег, юрисдикционных сертификаций.
- Нет бонус-игр, фриспинов, wild/scatter — только базовая игра (задел в конфиге есть, но не реализуем).
- Нет мобильных тач-жестов свайпа — управление кнопками/клавиатурой (тач работает как клик).

## Decisions

1. **Pixi v8 (`Application.init`) + TypeScript strict + Vite.** Один канвас на всю игру, `resizeTo: window`, собственный layout-корень с фиксированным дизайн-разрешением 1920×1080 и scale-to-fit + letterbox — так координаты зон фона и барабанов не зависят от окна.
2. **Математика отделена от презентации.** `src/game/math.ts` — чистые функции: `spinGrid(config, rng)` → сетка 5×3 + `evaluate(grid, config)` → список выигрышных линий и сумма. Исход фиксируется до старта анимации; визуал лишь доезжает до него (требование честности из slot-math).
3. **Виртуальные reel strips** (по ~64 позиции на барабан, разный вес символов по барабанам) — классический подход, даёт простую проверку частот и точный контроль RTP через `tools/simulate.mjs` (10M спинов, тот же config через переиспользуемый модуль без зависимостей от pixi).
4. **Нарезка атласа** — `Texture` c `frame` на общей `TextureSource` (координаты из `SYMBOL_GRID` в config). Фон — отдельный спрайт; зоны (тёмный центр) задаются в долях дизайна и подобраны под изображение.
5. **Состояния — явный конечный автомат**: `idle → spinning → stopping → evaluating → presenting → bigwin → (autoplay → spinning…)`. Транзишены в `Game.ts`; UI и звук подписываются на события через callback-шину, без глобальных синглтонов.
6. **Барабаны — `Ticker`-анимация контейнера с маской.** Каждый барабан держит ленту из N символов (5 видимых + буфер, дублирование головы ленты для бесшовной петли); остановка — замедление до целевой позиции + отскок (easing). Anticipation — продление фазы постоянной скорости + пульс рамки.
7. **Звук — один модуль `audio.ts`** поверх WebAudio (осцилляторы + шум для кликов), master gain, mute-флаг, разблокировка по первому pointerdown/keydown.
8. **Хранение** — ключ `grim-fortune:save:v1` (balance, betIndex, muted) с try/catch и значениями по умолчанию при повреждении.

## Risks / Trade-offs

- **RTP «на глаз» неточен** → митигируется симулятором 10M спинов в CI-подобной проверке (npm run simulate) и подгонкой strips до попадания в 92–96%.
- **Атлас — не power-of-two** → Pixi v8 (WebGL2/WebGPU) справляется без распаковки; на очень старых GPU теоретически возможна деградация — принимаем (цель — современные браузеры).
- **Кириллический текст в UI** — системный шрифт с фолбэками, без кастомных шрифтов, чтобы не тянуть ассеты; типографика решается стилем (letter-spacing, caps).
- **Скорость презентации затянет автоигру** → в автоигре презентация обычных выигрышей сокращается (таймауты ×0.5), Big Win всегда полный.
